# sim

Testbenches and PVT corner results (ngspice). harness/ carries the PVT corner definitions, evidence schema and record-id helpers (see harness/README.md). Simulation runs through `klt` (see characterize/ and item5/), not a local ngspice runner.

## item5/

T1 item 5 analog corner evidence (spec row 9): per-cell `klt sim` envelopes
for the four committed cells at TT / 1.20 V / 25 C — logical function at the
rails and full-grid delay/transition agreement with the committed Liberty
view, every measurement limit-checked and `spec_row`-tagged. See
`item5/README.md`; records under `item5/records/`, cited in the block
manifest as `evidence."5.analog"`.

## characterize/

Drives `klt characterize` and appends the raw per-arc delay / transition /
energy tables as an evidence record under
`sim/characterize/records/<record-id>.md`, using the harness record-id scheme
(`allocate_record_id`). Each record carries the slew and load axes, per-arc
values, the klt version and provenance, and the repo commit. Re-running mints a
new id; nothing is overwritten. Liberty formatting is always `klt`'s, never this
package's.

Two modes. The default **baseline leg** characterizes one existing
`sg13g2_stdcell` cell — the benchmark denominator of
`spec/0001-target-specification.md` ("Baseline Liberty") — and writes no
Liberty: it records measurements only.

```
python3 -m sim.characterize --pdk-dir <ihp-sg13g2 dir> [--corner tt|ff|ss] [--backend local|batch]
python3 -m unittest sim.characterize.tests.test_request
```

Library view (spec row 9): `--library` characterizes every cell of
`layout/example_config.json` (SPICE regenerated by `design/gen_netlists.py` from
that same config) into ONE `klt characterize` `cells` request. `klt` writes the
committed corner-named view under `views/` (`sg13g2_stdcells_tt_1p20v_25c.lib`
at the default corner, handed to it as `--lib`);
this package writes the `.lib.provenance` sidecar beside it (see
`views/README.md`) and appends one evidence record:

```
python3 -m sim.characterize --library --pdk-dir <ihp-sg13g2 dir>
```

`--pdk-dir` must be a **clean IHP-Open-PDK git checkout** (the `ihp-sg13g2`
variant directory of a clone, or the clone root). The runner captures its
commit (`pdk_provenance`) before klt runs or anything is written, refuses the
run when the revision cannot be recorded honestly — not a git checkout, no
commit, an origin that is not IHP-Open-PDK, or a dirty checkout — and records
the one snapshot in the record's `**PDK**` header line and the sidecar's
`pdk` object. How to check the PDK out at the pinned commit (and build the
OSDI models the request preloads) is documented in the root README,
"Reproducing the characterization".

One corner per invocation (`--corner tt|ff|ss`, TT/1.20 V/25 C by default).
FF/SS are one invocation per corner with `--backend batch`, never a local loop.
The default view path is corner-named — derived from the corner's PVT pairing
(`sg13g2_stdcells_tt_1p20v_25c.lib` at TT, `sg13g2_stdcells_ff_1p32v_m40c.lib`
at FF; negative temperatures spell `m` for minus) — so a non-default corner
never needs an explicit `--lib` to keep the committed TT view safe; pass
`--lib` only to write somewhere other than the default per-corner path.
